# Руководство пользователя Conveyor OS

Добро пожаловать в **Conveyor OS** — портативную, автономную операционную систему для автономной разработки и работы с ИИ-агентами.

Это руководство зашито прямо в вашу систему. Вы можете открыть его в любой момент:
* Клавишами: **`Super + F1`**
* Командой в терминале: **`conveyor-help`** (или **`conveyor-docs`**)
* Через лаунчер **Fuzzel** (`Super + Space` → «Руководство пользователя»)
