# 04. Распознавание голоса: Antigravity Live STT

В Conveyor OS на уровне операционной системы встроен инструмент голосового ввода (Speech-to-Text).  
Он позволяет надиктовывать промпты для агентов, сообщения в чат или комментарии к коду голосом, освобождая руки от рутинного набора текста.

---

## 1. Как пользоваться (Push-to-Talk / Toggle)

Вам не нужно открывать специальные окна или запускать утилиты:

1. Установите текстовый курсор в любое место (в терминал с Aider, в редактор `micro`, в строку поиска браузера или в форму ввода).
2. Нажмите сочетание клавиш:
   > **`Super + ~`** (клавиша `Windows` + тильда / русская буква `Ё`)
3. В правом верхнем углу всплывёт уведомление:  
   🎙️ **«Запись речи... Говорите. Нажмите Super+~ снова для отправки.»**
4. Надиктуйте задачу голосом.  
   *Пример:* «*Создай функцию валидации юзернейма, проверь длину от трёх до двадцати символов и выброси ValueError, если есть пробелы*».
5. Нажмите **`Super + ~`** повторно для завершения.
6. Система обработает аудио и **автоматически напечатает готовый текст прямо на месте вашего курсора** через утилиту `wtype` (а также сохранит копию текста в буфер обмена).

---

## 2. Настройка API-ключа для Antigravity Live STT

Для максимального качества распознавания (с идеальной расстановкой знаков препинания и пониманием технических терминов вроде `async/await`, `JSON`, `PostgreSQL`) система использует движок **Antigravity Live STT** (на базе Gemini Multimodal Audio).

### Где прописать ключ:
Создайте или откройте конфигурационный файл в домашней папке:
```bash
micro ~/.config/conveyor/antigravity.env
```
И добавьте строчку с вашим ключом:
```env
ANTIGRAVITY_API_KEY=ваш_ключ_здесь
```
Сохраните файл (`Ctrl + S`) и закройте (`Ctrl + Q`).  
Ключ подхватывается на лету, перезагрузка не требуется.

## 3. Автономный режим без интернета (Whisper Fallback)

Что делать, если интернета нет, а надиктовать текст голосом всё равно нужно?

В систему зашит автономный запасной движок **`whisper-cli`**:
1. Скачайте легковесную модель Whisper Small (~460 МБ) в папку моделей:
   ```bash
   curl -L -o /var/lib/models/ggml-small.bin "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin"
   ```
2. Если интернета нет или ключ API не задан, скрипт `conveyor-live-stt.sh` **автоматически переключится на локальный `whisper-cli`**.
3. Локальный Whisper работает полностью на процессоре (0 МБ VRAM), поэтому ваша видеокарта останется свободной для `llama.cpp` и ComfyUI.

---

## 4. Проверка микрофона

Если звук не записывается:
1. Откройте микшер громкости через терминал:
   ```bash
   pavucontrol
   ```
2. Перейдите во вкладку **«Input Devices» (Устройства ввода)**.
3. Убедитесь, что нужный микрофон (встроенный в ноутбук или USB-гарнитура) выбран по умолчанию и индикатор шкалы громкости реагирует на ваш голос.
