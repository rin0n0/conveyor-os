# 04. Работа с файлами: `Yazi` и `Thunar`

В Conveyor OS навигация по дискам и проектам сделана максимально наглядной: вам не обязательно помнить структуру каталогов Linux.

---

## 1. Терминальный проводник `Yazi`

**`yazi`** — это ультрабыстрый терминальный файловый менеджер нового поколения, написанный на Rust.

### Запуск:
В терминале наберите:
```bash
yazi
```
*(Или просто `ya`).*

### Возможности и управление:
* **Навигация стрелочками:**
  * `Стрелка вверх / вниз` (или `K / J`) — выбор файла.
  * `Стрелка вправо` (или `L` / `Enter`) — войти в папку или открыть файл в `micro`.
  * `Стрелка влево` (или `H`) — выйти на уровень выше.
* **Мгновенный предпросмотр справа:**  
  При наведении на любой файл справа в отдельной колонке отображается его содержимое (код с подсветкой синтаксиса, текст markdown, метаданные и даже картинки прямо в терминале).
* **Поиск:** нажмите `/` и начните вводить имя файла.
* **Выход:** нажмите `Q`.

---

## 2. Графический проводник `Thunar` (Обычные окна с папками)

Если вы хотите работать с файлами с помощью привычных окон мыши (перетаскивание Drag & Drop, контекстное меню):

### Запуск:
* Нажмите **`Super + Space`**, наберите **`thunar`** и нажмите `Enter`.
* Либо введите в терминале:
  ```bash
  thunar &
  ```

Откроется классический оконный проводник с боковой панелью, где сразу видны диск `SHARED` (`/mnt/shared`), домашняя папка, Корзина и подключенные флешки.
