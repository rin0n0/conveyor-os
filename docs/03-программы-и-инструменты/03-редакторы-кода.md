# 03. Редакторы кода: `Micro` и `Neovim`

В системе предустановлены два текстовых редактора под разные привычки и задачи:

---

## 1. Редактор `Micro` (Системный редактор по умолчанию)

**`micro`** — идеальный TUI-редактор для разработчиков, пришедших с Windows.  
Вам не нужно учить команды Vim, модальные режимы или специальные комбинации клавиш.

### Привычные горячие клавиши Windows:
* **`Ctrl + S`** — Сохранить файл.
* **`Ctrl + Q`** — Закрыть файл / Выйти из редактора.
* **`Ctrl + C`** — Скопировать выделенный фрагмент (напрямую в системный буфер обмена).
* **`Ctrl + V`** — Вставить из буфера обмена.
* **`Ctrl + X`** — Вырезать.
* **`Ctrl + Z`** — Отменить действие (Undo).
* **`Ctrl + Y`** — Повторить действие (Redo).
* **`Ctrl + F`** — Поиск по тексту (нажмите `Ctrl + N` для перехода к следующему совпадению).
* **Полноценная поддержка мыши:** можно кликать в любое место кода для установки курсора, выделять текст мышью как в Блокноте и скроллить колесом мыши.
* **Подсветка синтаксиса:** автоматически определяет Python, Rust, C++, JS, TOML, Markdown, YAML, Bash и др.

### Запуск:
```bash
micro main.py
```

## 2. Редактор `Neovim` + плагин `Diffview`

Для опытных пользователей и тех, кто предпочитает модальное редактирование, в систему зашит **`Neovim`** (`nvim`).

### Встроенный просмотр Git Diff: `Diffview`
В Neovim интегрирован плагин **`diffview.nvim`**:
* Чтобы визуально просмотреть все изменения в Git-репозитории в виде двухколоночного сравнения (как в VS Code или GitHub):
  ```bash
  nvim -c DiffviewOpen
  ```
* Закрыть просмотр диффа:
  ```vim
  :DiffviewClose
  ```

## 3. Графический редактор (VS Code / VSCodium)

Если вам обязательно нужен полноценный графический VS Code со всеми его расширениями:
1. Вы можете установить **VSCodium** через Flatpak:
   ```bash
   flatpak install flathub com.vscodium.codium
   ```
2. Запускать его через меню Fuzzel (`Super + Space` → `codium`).
