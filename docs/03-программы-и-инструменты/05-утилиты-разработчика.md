# 05. Утилиты разработчика

В Conveyor OS зашит современный стек инструментов для комфортной разработки без необходимости настраивать окружение с нуля:

---

## 1. Контроль версий: Git, `lazygit` и Jujutsu (`jj`)

* **`git`:** стандартный инструмент контроля версий. С настроенными улучшенными диффами `git-delta` и `difftastic` (`difft`).
* **`lazygit`:** стильный интерактивный TUI-клиент для Git.  
  Запуск в папке проекта:
  ```bash
  lazygit
  ```
  Позволяет визуально стейджить строки, разрешать конфликты слияния и делать коммиты клавишами за секунды.
* **Jujutsu (`jj`):** новая Git-совместимая система контроля версий от Google.  
  Она автоматически создает анонимные коммиты при каждом сохранении файла, поэтому вы никогда не потеряете написанный код, даже если забыли закоммитить изменения.

---

## 2. Поиск по коду: `ripgrep`, `fd` и `ast-grep`

* **`rg` (`ripgrep`):** самый быстрый в мире поиск текста по кодовой базе:
  ```bash
  rg "TODO"
  rg -i "connect_database" src/
  ```
* **`fd`:** быстрая и удобная замена старой команды `find`:
  ```bash
  fd "\.py$"
  fd -e toml
  ```
* **`ast-grep` (`sg`):** структурный поиск по синтаксическому дереву (AST):
  ```bash
  # Найти все вызовы console.log с любым аргументом:
  sg -p 'console.log($$$)'
  ```

---

## 3. Менеджер языков программирования: `mise`

**`mise`** — инструмент для управления версиями языков (Node.js, Python, Go, Rust, Ruby) в рамках каждого проекта:
* Позволяет мгновенно переключать версии интерпретаторов:
  ```bash
  mise use python@3.11
  mise use node@20
  ```
* Все настройки кэшей сборки и компиляторов уже оптимизированы в `~/.config/mise/config.toml`.

---

## 4. Очередь фоновых задач: `pueue`

**`pueue`** — фоновый диспетчер выполнения долгих задач (компиляция, обучение, тесты, тяжелые конвертации):
* Добавить долгую задачу в очередь:
  ```bash
  pueue add -- "cargo build --release"
  ```
* Посмотреть статус очереди:
  ```bash
  pueue status
  ```
* Текущее состояние очереди `pueue` также в реальном времени отображается в верхней панели **Waybar**!
