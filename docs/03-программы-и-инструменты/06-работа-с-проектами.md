# 06. Как работать с «Проектами» (`Super + P`) — гайд для программиста

Если вы пришли с Windows, понятие «проекты на уровне ОС» может сбивать с толку. Давайте разберём простыми словами, что это такое, зачем оно нужно и как в этом удобно писать код.

---

## 1. Что такое «Проект» в Conveyor OS?

В Windows вы обычно создаёте папку, открываете её в VS Code / PyCharm — и внутри IDE у вас сразу есть редактор, встроенный терминал, панель Git и дерево файлов.

В Conveyor OS роль такой лёгкой «IDE в терминале» выполняет связка **`Super + P` + `Foot` + `Zellij`**:
* **Физически** проект — это просто обычная папка внутри `~/Projects/` (например, `~/Projects/my-bot`).
* **Логически** для каждой такой папки система автоматически создаёт отдельную **живую сессию Zellij** (аналог рабочего пространства VS Code) с готовыми вкладками под код, терминал, Git и файлы.

---

## 2. Пошаговый сценарий: как создать и вести проект

### Шаг 1. Откройте переключатель проектов
* Нажмите **`Super + P`** (или кликните мышкой по кнопке **`📁 Проекты`** в левом верхнем углу панели).
* Выберите **`➕ Новый проект`** и введите короткое имя без пробелов, например `my-bot`.

### Шаг 2. Что сделает система за секунду
1. Создаст папку `~/Projects/my-bot`.
2. Автоматически инициализирует там репозиторий контроля версий (`git` / `jj`).
3. Откроет окно терминала с уже настроенными **тремя вкладками** (они видны в самой верхней строке окна терминала):

| Вкладка | Что внутри | Как использовать программисту |
|---|---|---|
| **`1:code`** | Две панели рядом: слева (60%) и справа (40%) | **Слева** открывайте код (`micro main.py`) или ИИ-агента (`aider` / `opencode`). **Справа** запускайте код, сервер и тесты (`python main.py`, `pytest`, `npm run dev`). |
| **`2:git`** | Слева консоль, справа **`lazygit`** | В любой момент переключились сюда → посмотрели изменённые строчки в `lazygit` → нажали `Space` (добавить в коммит) → `c` (написать сообщение) → `P` (запушить на GitHub). |
| **`3:files`** | Файловый менеджер **`yazi`** | Удобно смотреть дерево проекта стрелочками и быстро открывать любой файл по `Enter`. |

---

## 3. Главная фишка: переключение без потери контекста

Представьте: вы пишете `my-bot`, у вас запущен локальный сервер, открыты 3 файла и чат с агентом. Вдруг нужно срочно посмотреть лабораторную `lab-3`.

1. Вы нажимаете **`Super + P`** и выбираете `lab-3`.
2. Работаете с лабораторной.
3. Снова нажимаете **`Super + P`** и выбираете `my-bot` — **и попадаете ровно в ту же живую сессию**, где сервер всё ещё работает, а терминал помнит все команды!

Даже если вы случайно закрыли окно терминала (`Super + Q`), сессия `zellij` продолжает жить в фоне и мгновенно восстановится через `Super + P`.

---

## 4. Минимум клавиш внутри окна проекта (Zellij)

Подсказка по клавишам всегда видна в самом низу окна, но запомнить достаточно всего 4 сочетания:

| Сочетание | Действие |
|---|---|
| **`Alt + Стрелки`** (или `Alt + H/J/K/L`) | Перепрыгнуть между левой и правой панелью |
| **`Alt + 1` / `Alt + 2` / `Alt + 3`** (или клик мышкой!) | Переключиться между вкладками `1:code`, `2:git`, `3:files` |
| **`Alt + N`** | Открыть ещё одну дополнительную панель терминала |
| **`Ctrl + O`, затем `D`** | Отключиться от сессии (оставить работать в фоне) |

> **Совет:** в Zellij полностью работает **мышь** — можно просто кликать по вкладкам сверху и по нужной панели, чтобы перевести туда курсор!

## 5. Как подключить проект с диска `E:` (`/mnt/shared`) или открыть его в проводнике

* **Проект лежит на диске `E:` (чтобы открывать его и в Windows)?**  
  Просто сделайте на него символическую ссылку в `~/Projects` одной командой:
  ```bash
  ln -s /mnt/shared/my-windows-project ~/Projects/my-windows-project
  ```
  После этого он сразу появится в меню **`Super + P`**!
* **Хотите увидеть файлы проекта в обычном графическом проводнике?**  
  Нажмите **`Super + E`** (или кликните **`📂 Файлы`** на верхней панели) и откройте папку `Projects`.
