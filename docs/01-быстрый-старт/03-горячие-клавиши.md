# 03. Сводная таблица горячих клавиш

Клавиша **`Super`** (или **`Mod`**) — это клавиша с логотипом Windows на вашей клавиатуре.

---

## 1. Общие клавиши (работают в любой сессии)

| Сочетание клавиш | Действие |
|---|---|
| **`Super + Enter`** | Открыть терминал **Foot** |
| **`Super + Space`** или **`Super + D`** | Вызов быстрого поиска / лаунчера программ (**Fuzzel**) |
| **`Super + Q`** | Закрыть текущее активное окно |
| **`Super + F`** | Развернуть окно на весь экран (Fullscreen toggle) |
| **`Super + F1`** | **Открыть это руководство пользователя (User Manual)** |
| **`Super + ~`** (тильда / `Ё`) | **Голосовой ввод Antigravity Live STT** (нажать для записи, нажать для вставки текста) |
| **`Super + N`** | Настройки сети (графическое окно Network Connections) |
| **`Super + Shift + N`** | Быстрое переключение сетевых профилей (Аудитории / Дом / Wi-Fi) |
| **`Super + Shift + B`** | Менеджер устройств **Bluetooth** (наушники, геймпады) |
| **`Super + P`** | **Менеджер проектов** (`project-switcher` — выбор проекта и открытие Zellij) |
| **`Super + V`** | История буфера обмена (**cliphist** через меню Fuzzel) |
| **`PrintScreen`** | Сделать скриншот области экрана (копирует в буфер и сохраняет в `~/Pictures/Screenshots`) |

---

## 2. Навигация в DriftWM (Основная сессия: 2D-холст)

В DriftWM окна не сжимаются в мелкую мозаику, а размещаются на бесконечном двухмерном пространстве (как острова на карте проекта).

| Сочетание клавиш | Действие |
|---|---|
| **`Super + M`** | **Показать / скрыть интерактивную мини-карту (Driftmap)** |
| **`Super + H / J / K / L`** | Переместить фокус на соседнее окно (влево / вниз / вверх / вправо) |
| **`Super + Стрелки`** | Переместить фокус по стрелкам |
| **`Super + C`** | Отцентрировать холст на текущем активном окне |
| **`Super + =`** / **`Super + -`** | Приблизить (Zoom In) / Отдалить (Zoom Out) холст |
| **`Super + 0`** | Сбросить масштаб холста на 100% |
| **`Super + Shift + W`** | Масштабировать холст так, чтобы уместить все окна проекта на экране |
| **`Super + Tab`** | Переключиться на следующее окно |
| **`Super + Shift + Tab`** | Переключиться на предыдущее окно |
| **`Super + Shift + C`** | Перезагрузить конфигурацию DriftWM |

---

## 3. Навигация в Niri (Альтернативная сессия: ленточный тайлинг)

В Niri окна выстраиваются в бесконечную горизонтальную ленту, которая плавно прокручивается клавиатурой.

| Сочетание клавиш | Действие |
|---|---|
| **`Super + Left / Right`** (или **`H / L`**) | Переместиться по ленте влево / вправо |
| **`Super + Up / Down`** (или **`K / J`**) | Переместиться по вертикальной колонке вверх / вниз |
| **`Super + Shift + Left / Right`** | Переместить текущее окно влево / вправо по ленте |
| **`Super + O`** | Режим общего обзора (Overview) со всеми колонками |
| **`Super + R`** | Переключить режим изменения размера окна (Resize mode) |
| **`Super + 1 ... 9`** | Переключиться на виртуальный рабочий стол 1–9 |

---

## 4. Переключение раскладки клавиатуры

* **Переключение:** клавиша **`Alt + Shift`** (или `Super + Space` в Sway).
* **Индикатор:** текущий язык (`EN` / `RU`) всегда отображается в верхней панели Waybar справа.
