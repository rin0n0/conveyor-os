# 02. Как правильно ставить софт в Conveyor OS

> **ВАЖНОЕ ПРАВИЛО:**  
> **Не используйте `sudo dnf install` для обычных программ!**  
> Conveyor OS — это Image-Based (контейнерно-ориентированная) система. Корневой раздел `@root` перезаписывается целиком при каждом обновлении системы из GitHub.  
> Всё, что вы поставите через `dnf`, при следующем обновлении системы бесследно исчезнет или вызовет конфликт библиотек.

Для установки любых программ в системе есть два официальных и безопасных пути:

---

## 1. Десктопные приложения: `Flatpak` (Рекомендуется)

**Flatpak** — стандарт изоляции приложений в Linux. Каждая программа ставится в изолированную песочницу, не трогает системные файлы и **сохраняется при любых обновлениях Conveyor OS** (поскольку ставится в папку пользователя или `/var`).

Репозиторий **Flathub** уже подключен автоматически.

### Поиск программы:
```bash
flatpak search telegram
flatpak search obsidian
```

### Установка в один клик:
```bash
# Браузер Google Chrome:
flatpak install flathub com.google.Chrome

# Мессенджер Telegram:
flatpak install flathub org.telegram.desktop

# Заметки Obsidian:
flatpak install flathub md.obsidian.Obsidian

# Редактор VSCodium:
flatpak install flathub com.vscodium.codium
```

После установки ярлык программы сразу же появится в быстром меню **Fuzzel** (`Super + Space`).

---

## 2. Консольные утилиты и окружения разработки: `Distrobox`

Если вам нужны специфические компиляторы, утилиты из Ubuntu/Arch или пакеты, которых нет во Flatpak — используйте **`distrobox`**.

Distrobox позволяет запустить любую версию Linux (Ubuntu, Arch, Debian) прямо внутри терминала, но с **полным доступом к вашим файлам, домашней папке и видеокарте**:

### Создать контейнер с Ubuntu:
```bash
distrobox create --name my-ubuntu --image ubuntu:24.04
```

### Войти в него:
```bash
distrobox enter my-ubuntu
```
Внутри этого контейнера вы можете безопасно делать `sudo apt install`, компилировать любые пакеты и экспериментировать — это никак не затронет основную операционную систему.
