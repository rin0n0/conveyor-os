# 05. Видеокарты, драйверы NVIDIA и CUDA 13

Conveyor OS содержит гибридный стек ускорения вычислений, который умеет выжимать максимум из дискретных видеокарт и при этом работать на компьютерах без дискретной графики.

---

## 1. Как проверить статус видеокарты

После загрузки системы откройте терминал (`Super + Enter`) и выполните команду:
```bash
cat /run/gpu-profile.env
```

Она покажет текущий аппаратный профиль:
* **`GPU_BACKEND`:**
  * `cuda` — обнаружена видеокарта NVIDIA (Turing+), работают официальные драйверы, модели ускоряются через CUDA 13.
  * `vulkan` — используется универсальный бэкенд Vulkan (для карт AMD Radeon, Intel Arc или при включенном Secure Boot).
  * `cpu` — дискретная карта не найдена, вычисления идут на процессоре с инструкциями AVX2 / AVX-512.
* **`VRAM_GIB`:** объем видеопамяти, обнаруженный системой (например, `8`).
* **`LLAMA_DEVICES`:** устройства, на которых запущен инференс (например, `CUDA0`).

---

## 2. Проверка состояния NVIDIA (`nvidia-smi`)

Если у вас установлена карта NVIDIA:
```bash
nvidia-smi
```
Утилита покажет:
* Версию драйвера NVIDIA и версию CUDA.
* Текущую температуру GPU и энергопотребление.
* Занятый объем видеопамяти и список процессов, использующих GPU.

---

## 3. Secure Boot и драйвер NVIDIA

* Модули ядра NVIDIA в сборке являются открытыми, но не имеют фабричной подписи Microsoft UEFI CA.
* **Поэтому на домашнем ПК с видеокартой NVIDIA рекомендуется отключить Secure Boot в BIOS.**
* Если Secure Boot включен: ядро Linux заблокирует загрузку проприетарного драйвера NVIDIA (`$lockdown`). Система всё равно загрузится, но видеокарта переключится на открытый драйвер `nouveau` / Vulkan.
