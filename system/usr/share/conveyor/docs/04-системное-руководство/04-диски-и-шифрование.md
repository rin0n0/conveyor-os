# 04. Диски, файловая система Btrfs и шифрование LUKS2

Накопитель Intel SSD 545s размечен по строгой отказоустойчивой схеме, гарантирующей безопасность данных и высокую скорость работы через USB.

---

## 1. Схема разделов накопителя (256 ГБ)

```
[ Физический диск Intel SSD 545s (238.47 GiB) ]
├── Раздел 1: [  1.0 GiB  ] FAT32 (EFI)     -> Загрузчик UEFI (\EFI\BOOT\BOOTX64.EFI)
├── Раздел 2: [  2.0 GiB  ] ext4 (/boot)    -> Ядро Linux (vmlinuz) и initramfs
├── Раздел 3: [ 50.0 GiB  ] exFAT (SHARED)  -> Общий буфер: Диск E: в Windows / /mnt/shared в Linux
├── Раздел 4: [ ~160 GiB  ] LUKS2 (Btrfs)   -> Зашифрованное хранилище системы и данных
└── Резерв:   [ ~25.0 GiB ] Не размечено    -> Over-provisioning (аппаратный ресурс износа ячеек TLC)
```

---

## 2. Подтома Btrfs (Эластичные виртуальные диски)

Внутри зашифрованного раздела 4 файловая система **Btrfs** делит общее пространство на логические подтома:

| Подтом | Точка монтирования | Особенности и назначение |
|---|---|---|
| **`@root`** | `/` | Сама операционная система. Сжатие `zstd:3` включено. При обновлении перезаписывается целиком. |
| **`@home`** | `/var/home` | Ваша домашняя папка, профили, ключи, Git-репозитории. **Установщик никогда её не трогает**. |
| **`@models`** | `/var/lib/models` | Веса локальных моделей нейросетей. **CoW и сжатие принудительно отключены (`chattr +C`)**, чтобы 10-гигабайтные файлы не фрагментировали диск при передаче в VRAM. |
| **`@containers`** | `/var/lib/containers` | Хранилище Podman и Docker. |
| **`@var_cache`** | `/var/cache` | Системные кэши. |
| **`@snapshots`** | — | Зарезервировано под мгновенные снимки файловой системы. |

---

## 3. Шифрование LUKS2

Раздел 4 защищен промышленным стандартом **LUKS2** с алгоритмом `aes-xts-plain64` (ключ 512 бит) и стойким к аппаратному подбору хешированием `Argon2id`.

### Как сменить пароль шифрования диска:
Если вы хотите изменить пароль разблокировки диска:
```bash
sudo cryptsetup luksChangeKey /dev/sdX4
```
*(Сначала утилита запросит старый пароль, затем дважды новый).*
