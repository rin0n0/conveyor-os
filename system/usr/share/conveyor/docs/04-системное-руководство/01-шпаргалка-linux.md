# 01. Шпаргалка команд Linux для разработчика на Windows

Если вы привыкли к PowerShell и командной строке Windows, вот краткий переводчик основных концепций и команд в Linux:

---

## 1. Навигация по файлам и каталогам

В Linux нет букв дисков (`C:`, `D:`, `E:`). Всё дерево файлов начинается с единого корня **`/`**.

| Задача в Windows (PowerShell) | Команда в Linux (Bash) | Пояснение |
|---|---|---|
| `cd E:\` (диск обмена) | `cd /mnt/shared` | Переход в раздел обмена с Windows |
| `cd ~` или `cd $HOME` | `cd ~` или просто `cd` | Переход в личную домашнюю папку (`/var/home/conveyor`) |
| `dir` или `ls` | `ls -la` | Показать список файлов с правами и скрытыми файлами |
| `copy file1 file2` | `cp file1 file2` | Скопировать файл |
| `move file1 file2` | `mv file1 file2` | Переместить или переименовать файл |
| `del file` / `rmdir /s` | `rm file` / `rm -rf folder` | Удалить файл / Удалить папку со всем содержимым |
| `mkdir folder` | `mkdir -p folder/subfolder` | Создать папку (флаг `-p` создаст недостающие родительские) |
| `Get-Content file` | `cat file` (или `micro file`) | Вывести содержимое файла в терминал |

---

## 2. Процессы, память и порты

| Задача | Команда в Linux | Что делает |
|---|---|---|
| Диспетчер задач (Task Manager) | `btop` | Красивый интерактивный монитор CPU, RAM, дисков и процессов |
| Мониторинг видеокарты | `nvtop` | Графический монитор загрузки GPU и VRAM в реальном времени |
| Состояние видеокарты NVIDIA | `nvidia-smi` | Официальная утилита статуса карт NVIDIA и драйверов |
| Посмотреть свободную оперативку | `free -h` | Показывает RAM и zram swap в человекочитаемом виде (ГБ/МБ) |
| Кто занял порт 8080? | `ss -tulpn \| grep 8080` | Показывает процесс, слушающий данный сетевой порт |
| Принудительно убить процесс | `kill -9 <PID>` или `killall <имя>` | Завершить процесс по номеру или имени |

## 3. Управление службами (Аналог `services.msc`)

В Linux системными службами управляет **`systemd`** через утилиту `systemctl`:

* Посмотреть статус службы (например, сервера моделей):
  ```bash
  systemctl status llama-swap
  ```
* Перезапустить службу:
  ```bash
  sudo systemctl restart llama-swap
  ```
* Посмотреть живой журнал логов службы:
  ```bash
  journalctl -u llama-swap -f
  ```

---

## 4. Права администратора: `sudo`

В Windows вы нажимаете правой кнопкой мыши *«Запуск от имени администратора»*.  
В Linux для выполнения системных команд перед ними пишут **`sudo`**:
```bash
sudo systemctl restart NetworkManager
```
При первом выполнении `sudo` терминал запросит ваш пароль пользователя.
*(Символы при вводе пароля скрыты — просто наберите пароль и нажмите Enter).*
