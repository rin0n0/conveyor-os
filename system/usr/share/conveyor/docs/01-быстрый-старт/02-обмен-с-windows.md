# 02. Обмен файлами с Windows и раздел SHARED

На накопителе Conveyor OS выделен универсальный раздел **`SHARED`** размером **50 ГиБ**.  
Он отформатирован в файловую систему **exFAT** — официальный стандарт Microsoft, который одинаково быстро, надёжно и без дополнительных драйверов работает как в Windows 10/11, так и в Linux.

---

## 1. Где находится этот раздел?

* **В Windows:**  
  Как только вы подключаете SSD к компьютеру, Windows сразу монтирует этот раздел как обычный логический диск (обычно **диск `E:`** или `D:`).  
  Остальные 3 раздела (EFI, Boot и зашифрованный LUKS2) Windows корректно игнорирует и не предлагает форматировать.
* **В Conveyor OS:**  
  Раздел автоматически монтируется по пути:
  ```text
  /mnt/shared
  ```
  *(В файловом менеджере `yazi` или `thunar` вы найдете его в корне файловой системы или по быстрой ссылке).*

---

## 2. Сценарии использования

### А. Скачивание тяжелых моделей и файлов в Windows
Вместо того чтобы качать многогигабайтные веса нейросетей или датасеты через консоль в Linux:
1. Загрузитесь в привычный Windows с быстрым браузером, торрентами или IDM.
2. Сохраните скачанный файл (например, `model.gguf` или чекпоинт `flux.safetensors`) прямо на диск:
   ```text
   E:\models\
   ```
3. Перезагрузитесь в Conveyor OS.
4. Файл уже ждет вас по адресу `/mnt/shared/models/`! Никаких промежуточных облаков или лишних циклов перезаписи SSD.

### Б. Перенос исходного кода и проектов
Вы можете разрабатывать проект в Conveyor OS, сохраняя его в `/mnt/shared/projects/my-app`.  
Тогда, вернувшись в Windows, вы сможете открыть ту же самую папку в обычном Visual Studio, Rider или VS Code.

### В. Запуск Conveyor OS в один клик (`Boot-Conveyor-OS.cmd`)
В корне раздела `SHARED` находится системная папка `ConveyorOS`:
```text
E:\ConveyorOS\
├── Boot-Conveyor-OS.cmd
└── Conveyor-Boot.ps1
```
* **Как пользоваться:**  
  Запустите `Boot-Conveyor-OS.cmd` от имени Администратора.  
  Скрипт определит физический диск, найдет раздел EFI Conveyor OS, создаст пункт в загрузчике Windows и предложит перезагрузить ПК прямо в нашу ОС без входа в BIOS.
* **Как удалить пункт из меню Windows:**  
  Если вы хотите удалить пункт из меню загрузки Windows: откройте PowerShell от администратора в этой папке и выполните:
  ```powershell
  .\Conveyor-Boot.ps1 -Remove
  ```

## 3. Права доступа и безопасность

* В Conveyor OS раздел `/mnt/shared` монтируется с параметрами:
  `uid=1000,gid=1000,umask=022,iocharset=utf8,nofail`
* Это гарантирует, что пользователь `conveyor` имеет **полные права на чтение и запись** без необходимости вводить `sudo`.
* Флаг `nofail` гарантирует, что даже если Windows завершила работу некорректно (быстрый запуск Windows Fast Startup оставил метку «dirty bit»), Conveyor OS всё равно успешно загрузится.
