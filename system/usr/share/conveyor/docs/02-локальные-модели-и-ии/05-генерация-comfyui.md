# 05. Генерация изображений: `ComfyUI`

В Conveyor OS можно запускать популярный инструмент генерации изображений **ComfyUI** (на базе Stable Diffusion, SDXL, Flux) с максимальной производительностью на вашей видеокарте и **без дублирования тяжелых моделей на диске**.

---

## 1. Быстрый запуск в один клик

В систему встроен скрипт автоматической установки и запуска:
```bash
conveyor-comfyui.sh
```

### Что происходит при первом запуске:
1. Скрипт клонирует свежий репозиторий ComfyUI в вашу домашнюю папку `~/comfyui`.
2. Через пакетный менеджер **`uv`** (написанный на Rust) разворачивает виртуальное окружение и ставит PyTorch с аппаратным ускорением **CUDA 12.4** (для карт NVIDIA) или **ROCm** (для карт AMD). Установка занимает всего около **1 минуты** (вместо 15–20 минут через обычный `pip`).
3. Автоматически связывает папки чекпоинтов, LoRA и VAE с разделом `E:\models\comfyui` (`/mnt/shared/models/comfyui`).
4. Поднимает сервер на `http://127.0.0.1:8188` и автоматически открывает браузер Firefox с готовым интерфейсом.

При повторных запусках скрипт просто стартует сервер за 2 секунды.

---

## 2. Общие модели с Windows (Экономия места)

Чекпоинты SDXL и Flux весят от 6 до 15 ГБ каждый. На SSD 256 ГБ хранить две копии (одну для Windows, одну для Linux) нерационально.

Благодаря разделу `SHARED`:
* В Windows сохраняйте ваши `.safetensors` чекпоинты в:
  ```text
  E:\models\comfyui\checkpoints\
  ```
* А LoRA-файлы в:
  ```text
  E:\models\comfyui\loras\
  ```
В Conveyor OS скрипт `conveyor-comfyui.sh` создаёт на них мгновенные символические ссылки. Файлы физически лежат в одном экземпляре на диске `E:`, экономя десятки гигабайт свободного места!

---

## 3. Видеопамять (8 ГБ VRAM)

* Текстовый сервер `llama-swap` автоматически выгружает большие языковые модели из VRAM при 15–60 минутах простоя.
* Перед запуском тяжелой генерации в ComfyUI вы можете принудительно убедиться, что VRAM свободна:
  ```bash
  nvidia-smi
  ```
  Если видеопамять чиста, все **8 ГБ VRAM** будут полностью отданы на генерацию картинок в высоком разрешении.
