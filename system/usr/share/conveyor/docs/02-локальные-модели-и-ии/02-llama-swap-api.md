# 02. Локальный API-сервер: `llama-swap`

В Conveyor OS запуск и маршрутизацию нейросетей берёт на себя фоновая системная служба **`llama-swap.service`**.

Она слушает адрес:
```text
http://127.0.0.1:8080/v1
```
и предоставляет **100% совместимый с OpenAI и Anthropic REST API**.

---

## 1. Как устроен жизненный цикл модели в видеопамяти

В видеокартах с 8 ГБ VRAM невозможно одновременно держать в памяти тяжелую модель кода, модель рассуждений и ComfyUI для генерации картинок.

`llama-swap` решает эту проблему автоматически:
1. **Запуск по требованию (On-Demand):**  
   Когда ваш редактор или агент шлёт запрос (например, к модели `coder`), `llama-swap` проверяет, загружена ли она. Если нет — за 5–10 секунд поднимает процесс `llama-server` с нужными весами и заливает слои в VRAM.
2. **Эксклюзивная группа VRAM (`vram_8gb_exclusive`):**  
   Модели `coder`, `fast` и `think` объединены в группу взаимоисключения с параметром `swap: true`. Если работала модель `coder`, а вы обратились к `think` — `llama-swap` корректно выгружает `coder` и только потом загружает `think`.
3. **Автоматическая выгрузка по таймауту (TTL):**  
   Если вы закончили писать код и не отправляете запросы:
   * Модель `fast` выгрузится из VRAM через **15 минут** бездействия.
   * Модель `think` выгрузится через **30 минут**.
   * Модель `coder` выгрузится через **60 минут**.  
   Видеокарта остывает, а все **8 ГБ VRAM освобождаются** под другие задачи (например, ComfyUI или игры).

## 2. Поддерживаемые имена моделей (Алиасы)

Любой инструмент (Aider, OpenCode, расширения для VS Code вроде Continue / Cline) можно настроить на `http://127.0.0.1:8080/v1`.

Вы можете указывать следующие имена моделей:

| Псевдоним в запросе | Куда маршрутизируется | Какая модель отвечает |
|---|---|---|
| `coder`, `default`, `qwen-coder` | Роль `coder` | Файл, привязанный к `[coder]` (`active-coder.gguf`) |
| `gpt-4o`, `claude-3-5-sonnet` | Роль `coder` | Перенаправляется на локальную модель кода |
| `fast`, `chat`, `fast-triage` | Роль `fast` | Файл, привязанный к `[fast]` (`active-fast.gguf`) |
| `gpt-4o-mini` | Роль `fast` | Перенаправляется на быструю модель |
| `think`, `o1`, `deepseek-r1` | Роль `think` | Файл, привязанный к `[think]` (`active-think.gguf`) |
| `embed`, `text-embedding-3-small` | Роль `embed` | Файл эмбеддингов (`active-embed.gguf`) |

## 3. Проверка статуса и управление

### Проверить статус службы:
```bash
systemctl status llama-swap
```

### Посмотреть список активных моделей через API:
```bash
curl -s http://127.0.0.1:8080/v1/models | jq
```

### Быстрый тестовый запрос через curl:
```bash
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "coder",
    "messages": [{"role": "user", "content": "Напиши Hello World на Python"}]
  }'
```

### Просмотр логов работы сервера в реальном времени:
```bash
journalctl -u llama-swap -f
```
