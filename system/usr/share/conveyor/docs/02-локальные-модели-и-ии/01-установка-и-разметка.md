# 01. Установка и разметка локальных моделей (`conveyor-model`)

В Conveyor OS локальный запуск нейросетей организован по модульному принципу: вам не нужно вручную прописывать гигантские параметры запуска в консоли.

Вместо этого в системе работает диспетчер **`llama-swap`**, а привязкой моделей управляет утилита:
```bash
conveyor-model
```

---

## 1. Концепция ролей (Сценариев использования)

Вместо привязки к конкретным именам файлов (например, `qwen2.5-coder-7b-instruct-q4_k_m.gguf`), все программы и агенты в Conveyor OS обращаются к **стандартизированным ролям**:

| Роль (Alias) | Назначение | Рекомендуемый размер | В какую VRAM влезает |
|---|---|---|---|
| **`coder`** | Основная модель для написания кода (Aider, OpenCode, VS Code) | 7B – 14B Q4_K_M (~4.7 – 9 ГБ) | 8 ГБ VRAM (полностью или с оффлоадом) |
| **`fast`** | Быстрые ответы, чат, триаж задач, мгновенные справки | 2B – 4B Q4_K_M (~1.5 – 2.5 ГБ) | 4–8 ГБ VRAM (летает со скоростью 60+ т/с) |
| **`think`** | Модель глубоких рассуждений (DeepSeek-R1, QwQ) | 7B – 14B Q4_K_M (~4.7 – 9 ГБ) | 8 ГБ VRAM |
| **`embed`** | Векторные эмбеддинги для поиска по кодовой базе (RAG) | 0.5B – 1B (~300 – 600 МБ) | Работает на CPU (0 МБ VRAM) |
| **`comfy-checkpoint`** | Чекпоинты генерации картинок для ComfyUI (SDXL, Flux) | 6 – 12 ГБ (`.safetensors`) | 8 ГБ VRAM |
| **`comfy-lora`** | LoRA-адаптеры для ComfyUI | 50 – 200 МБ | 8 ГБ VRAM |

---

## 2. Пошаговая инструкция: как добавить скачанную модель

### Шаг 1. Скачайте модель
Вы можете скачать модель формата **`.gguf`** (для текста/кода) или **`.safetensors`** (для картинок):
* **Из Windows:** сохраните файл прямо на диск `E:\models\` (раздел SHARED).
* **Из Linux:** скачайте в папку `~/Downloads` или положите в `/mnt/shared/models/`.

### Шаг 2. Запустите регистратор моделей
Откройте терминал (`Super + Enter`) и запустите:
```bash
conveyor-model
```

Утилита автоматически просканирует диск `E:`, папку `Downloads` и выведет список найденных файлов:
```text
==========================================================
Conveyor OS: Менеджер установки и разметки моделей
==========================================================
Поиск скачанных весов (.gguf, .safetensors, .ckpt)...
Найдены следующие файлы:
 [ 1] Qwen2.5-Coder-7B-Instruct-Q4_K_M.gguf      (4.7G) [/mnt/shared/models]
 [ 2] DeepSeek-R1-Distill-Qwen-7B-Q4_K_M.gguf    (4.7G) [/mnt/shared/models]
 [ 3] gemma-2-2b-it-Q4_K_M.gguf                  (2.5G) [/mnt/shared/models]
 [ 4] dreamshaperXL_v2.safetensors               (6.4G) [/mnt/shared/models]
----------------------------------------------------------
Выберите номер файла для установки [1-4]: 1
```

### Шаг 3. Назначьте роль
Выберите, за какой сценарий будет отвечать эта модель:
```text
Выберите сценарий авто-использования:
 1) [coder]            Основная модель кода (для Aider, OpenCode, VS Code)
 2) [fast]             Быстрая модель (короткие ответы, чат, триаж)
 3) [think]            Глубокие рассуждения / логика (DeepSeek-R1 / QwQ)
 4) [embed]            Векторные эмбеддинги для RAG и поиска
 5) [vision]           Мультимодальная модель (с распознаванием изображений)
 6) [comfy-checkpoint] Чекпоинт для генерации изображений (SD 1.5, SDXL, Flux)
 7) [comfy-lora]       LoRA для ComfyUI
----------------------------------------------------------
Введите номер сценария [1-7]: 1
```

### Шаг 4. Выберите способ подключения (Симлинк или Копия)
```text
Способ подключения:
 1) Символическая ссылка (Рекомендуется: экономит место, файл остается на диске E:)
 2) Полная копия в зашифрованный сабволюм @models (NoCoW)
Выберите способ [1-2, Enter = 1]: 1
```
* **Символическая ссылка (рекомендуется):** файл физически остаётся на диске `E:`, не дублируя место на SSD. Он мгновенно подключается в систему за 1 миллисекунду!
* **Копия:** файл копируется в зашифрованный сабволюм `@models` с отключенной фрагментацией (`chattr +C NoCoW`).

## 3. Просмотр текущей разметки ролей

Чтобы в любой момент увидеть, какая модель назначена на какую роль:
```bash
conveyor-model list
```
Пример вывода:
```text
==========================================================
Conveyor OS: Active Model Scenarios (llama-swap & ComfyUI)
==========================================================
СЦЕНАРИЙ (ALIAS)   ТЕКУЩИЙ ФАЙЛ                     РАЗМЕР      
----------------------------------------------------------
[coder]            Qwen2.5-Coder-7B-Instruct-Q4...  4.7G        
[fast]             gemma-2-2b-it-Q4_K_M.gguf        2.5G        
[think]            DeepSeek-R1-Distill-Qwen-7B...   4.7G        
[embed]            (не назначен)                    -           
[vision]           (не назначен)                    -           
----------------------------------------------------------
ComfyUI Checkpoints (/mnt/shared/models/comfyui/checkpoints):
  * dreamshaperXL_v2.safetensors (6.4G)
==========================================================
```

Всё готово! Служба `llama-swap` мгновенно подхватывает новые файлы без перезапуска.
