# 03. Консольные ИИ-агенты: `aider` и `opencode`

В Conveyor OS предустановлены два ведущих консольных инструмента автономного написания кода: **Aider** и **OpenCode CLI**.

Они оба «из коробки» знают о нашем локальном сервере `llama-swap` и могут работать как с локальными весами (без интернета), так и с внешними облачными API (OpenAI, Anthropic, Gemini).

---

## 1. Aider (`aider-chat`)

**Aider** — инструмент парного программирования в терминале. Он умеет читать структуру вашего репозитория, строить AST-граф зависимостей, вносить изменения в несколько файлов одновременно и автоматически создавать осмысленные коммиты в Git.

### Быстрый запуск в папке проекта:
```bash
cd /mnt/shared/projects/my-app
aider
```

### Запуск с указанием конкретной локальной модели:
```bash
# Работа с локальной моделью кода (роль coder):
aider --model openai/coder --openai-api-base http://127.0.0.1:8080/v1 --openai-api-key none

# Быстрый чат без изменений файлов:
aider --model openai/fast --openai-api-base http://127.0.0.1:8080/v1 --openai-api-key none
```

### Полезные команды внутри чата Aider:
* `/add <файл>` — добавить файл в контекст редактирования (агент сможет его менять).
* `/read-only <файл>` — добавить файл только для чтения (например, документацию или схему API).
* `/drop <файл>` — убрать файл из контекста.
* `/undo` — откатить последние изменения, сделанные агентом.
* `/diff` — посмотреть текущую разницу изменений в коде.
* `/test <команда>` — запустить тесты (например, `/test pytest`), при ошибках агент сам исправит код!
* `/exit` (или `Ctrl + D`) — выйти из чата.

---

## 2. OpenCode CLI (`opencode`)

**OpenCode** — более автономный агент, способный выполнять комплексные инженерные задачи: самостоятельно искать файлы по проекту, вызывать команды терминала, создавать новые модули и проводить рефакторинг.

### Быстрый запуск:
```bash
cd /path/to/project
opencode
```

В интерактивном режиме вы можете попросить его:
> *«Создай REST API сервис на FastAPI с авторизацией по JWT и базой SQLite. Добавь тесты и запусти их.»*

OpenCode сам создаст нужные файлы, запустит установку зависимостей через `uv` и прогонит тесты.

## 3. Советы для максимальной эффективности на локальных моделях

1. **Добавляйте в контекст только нужные файлы:**  
   Локальные модели (7B–14B) имеют контекстное окно от 16k до 32k токенов. Не добавляйте всю кодовую базу сразу — используйте `/add` только для тех 2–3 файлов, которые непосредственно связаны с задачей.
2. **Используйте структурный поиск `ast-grep`:**  
   В систему зашит `ast-grep` (`sg`) — инструмент синтаксического поиска по AST-дереву. С его помощью можно за миллисекунды находить вызовы функций или паттерны классов по всему проекту.
3. **Голосовой ввод промптов:**  
   Нажмите **`Super + ~`**, надиктуйте сложную задачу голосом (на русском языке со спецтерминами), нажмите **`Super + ~`** ещё раз — и текст сам напечатается в консоль агента!
